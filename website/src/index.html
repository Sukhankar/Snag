A shorter route to the cause

The report is only
the beginning.

Keep the evidence and the follow-up together, from the first click to the final reply.

01 / IN THE CLIENT'S APP

Catch the context.

Open the widget with Alt+B or its floating button. Add a screenshot. The last 20 browser events come along with the report.

02 / IN YOUR TEAM'S INBOX

Give it an owner.

Assign, prioritise, and classify tickets. Link duplicates so the same problem doesn't turn into five separate investigations.

03 / BACK TO THE REPORTER

Finish the conversation.

Reply in the ticket. Keep internal notes with the team. Live updates bring the answer back to the person who asked.

Repository access and Docker Compose required.

01 / LOCAL SETUP
git clone https://github.com/Sukhankar/Snag.git
cd Snag
cp .env.example .env
# Set your database password and Owner credentials.
docker compose up --build -d

Then open localhost:3000 and sign in as the Owner.
