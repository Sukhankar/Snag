Before you get started

A few practical answers.

Is Snag a hosted service?

This project is a self-hosted application. You run the application and database. The getting-started guide covers a local Compose setup; deployment guidance covers the next steps.

Who is it built for?

Agencies, delivery teams, and product teams supporting multiple client applications. It is especially useful when support and engineering need to share the same evidence and conversation.

Do reporters need a team account?

No. The widget uses a reporter token to scope My Tickets. Team members sign in to the dashboard and receive permissions through their role.

What does a production deployment need?

HTTPS in front of the dashboard and API, regular PostgreSQL backups, and a data-retention policy for screenshots and telemetry. Run one API instance: live updates are delivered in-process. Team sign-in uses email and password with role-based permissions; single sign-on and two-factor sign-in are on the roadmap. The deployment guide covers each step.
