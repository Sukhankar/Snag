Privacy policy

A factual account of this website, separate from data collected by a Snag deployment.

Scope

This policy covers the Snag website and its documentation. It does not cover data processed by a Snag instance that you or another organisation operate. Questions about this website can be raised on the project’s GitHub repository.

What this website does

The site has no registration form, payment flow, analytics SDK, advertising tracker, or live ticket submission. The product preview on the home page uses sample data and sends nothing to a server. The site’s own code does not set cookies.

Requests and hosting

Loading the site sends normal HTTP requests to the hosting provider. Those requests may include an IP address, browser information, requested URL, and referrer. A hosting platform may maintain access logs or use its own authentication cookies. Those logs are governed by the hosting provider’s own policies.

Preferences and offline copies

The site opens in a dark appearance; you can switch to light or follow your device. If you choose to remember settings, the site stores the theme preference in this browser. Optional offline access caches only this website’s static pages and assets, not tickets, API responses, credentials, or dashboard sessions. See the cookie and storage notice for the exact keys and controls.

Links to other services

Following a GitHub or reference link sends you to that service. Fonts are supplied by the device; this website does not request remote fonts. No third-party analytics are bundled with the site.

Your self-hosted Snag instance

A deployed Snag application can process reporter names and emails, ticket content, screenshots, attachments, browser telemetry, and team account data. That deployment’s operator decides how it is used, who can access it, and how long it is kept. The website controls do not delete or manage data in a separate Snag application.

Requests and retention

You can remove this website’s stored preferences and offline copies through Cookie & storage settings. For hosting logs or application records, contact the relevant operator through the contact details supplied with your deployment. For questions about this website, open an issue on the GitHub repository.
