DEVELOPER FIELD GUIDE / 02

A small script. A useful report.

Install the widget without moving your users into another application.

Script-tag integration

Replace the host and project key below. Add the application origin in Projects before testing.

HTML
<script
  src="https://snag.example.com/widget.min.js"
  data-project-key="pk_your_project_key"
  data-app-version="2.4.1"
  data-mask-text="true"
  async
></script>

Options

AttributeBehaviour
data-project-keyRequired project key.
data-apiAPI origin. Defaults to the script origin.
data-app-versionVersion included with submitted reports.
data-user-name / data-user-emailPrefill reporter identity.
data-fab="false"Hide the floating button; Alt+B and the JS API still work.
data-mask-text="true"Do not record clicked element text.
data-themelight or dark.
data-accentHex accent colour.

Control it from your app

Call these after the widget script has loaded. Manual initialisation requires a project key; repeat initialisation is ignored.

JAVASCRIPT
window.Snag.init({
  projectKey: 'pk_your_project_key',
  api: 'https://snag.example.com',
  maskText: true
});
window.Snag.identify({ name: 'Example reporter' });
window.Snag.open();
// Also available: close() and toggle()

Reporter identity

The widget generates a URL-safe reporter token and keeps it in localStorage when available. This token scopes My Tickets. A project key is not a private administrator credential.

Telemetry and styles

A closed Shadow DOM separates widget styling from host CSS. The in-memory buffer holds 20 events: clicks, route changes, errors, and failed network requests. Input values are not recorded and URL query strings are stripped. Screenshots and uploaded files can still contain sensitive information; inspect what you attach.
