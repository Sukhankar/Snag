DEVELOPER FIELD GUIDE / 05

The HTTP surface.

Widget routes serve reporters. Admin routes require an authenticated user session or the optional service token.

Widget headers

HeaderRequirement
OriginMust match the project allowlist; Referer is the fallback.
X-Project-KeyProject key from the dashboard.
X-Reporter-TokenAnonymous reporters: 16–64 URL-safe characters (letters, digits, underscore or hyphen). Keep it stable for a reporter. Snag stores only its SHA-256 hash.
X-Reporter-IdentitySigned reporters, instead of the token: v1.<user>.<expires>.<signature> from the host app's server. See signed users. An invalid value returns 401 and never falls back to anonymous.
Content-Typeapplication/json for JSON requests.

Create a ticket

Terminal
curl -i http://localhost:8080/api/v1/widget/tickets \
  -H 'Origin: http://localhost:5173' \
  -H "X-Project-Key: $PROJECT_KEY" \
  -H "X-Reporter-Token: $REPORTER_TOKEN" \
  -H 'Content-Type: application/json' \
  --data '{"title":"Receipt is blank","category":"bug"}'

The title is required and limited to 255 characters. Category defaults to bug; priority defaults to P2_Normal. A successful request returns HTTP 201 with ticket_code, status, and created_at. See the test setup for environment variables.

Widget routes

MethodPathPurpose
POST/api/v1/widget/ticketsCreate a report.
GET/api/v1/widget/ticketsList this reporter’s tickets.
GET/api/v1/widget/tickets/{code}Read a ticket and its public conversation.
POST/api/v1/widget/tickets/{code}/messagesReply with body and optional attachments.
POST/api/v1/widget/stream-ticketExchange the reporter headers for a single-use stream ticket, valid for 60 s.
GET/api/v1/widget/stream?key=…&ticket=…SSE events: ticket.created, ticket.updated, message.created. A signed reporter's stream ends when their token expires.

Authentication

POST /api/v1/auth/login takes email and password. Use the returned token as Authorization: Bearer …. POST /api/v1/auth/logout revokes the session. Keep tokens out of URLs and browser-accessible configuration. The widget stream URL carries only a single-use ticket.

Admin route groups

Resource under /api/v1/adminMethods / purpose
/me; /me/passwordGET current user; POST password change.
/tickets; /tickets/{id}GET list (filters include assignee_id = a user id, me or none) or detail with its activity log; PATCH ticket fields, subject to permissions.
/tickets/{id}/messages; /tickets/{id}/broadcastPOST replies or broadcast to linked reporters.
/attachments/{id}; /streamGET attachment content or SSE.
/projects; /projects/{id}GET/POST projects; PATCH a project, including identity_required.
/projects/{id}/identity-secretPOST: enable or rotate signed reporters. The response holds the secret, once only. DELETE: turn them off.
/teams; /teams/{id}; /users/directoryGET directories (each team lists member_ids); POST /teams to create, optionally with member_ids; PATCH/DELETE a team. Team names are unique regardless of case.
/teams/{id}/members; /users/{id}/teamsPUT replaces a team's members (user_ids) or a user's teams (team_ids). Needs teams.manage. A user can belong to any number of teams.
/reports/amcGET bug vs change-request counts per project for from–to (YYYY-MM-DD, default this month).
/users; /users/{id}GET/POST users; PATCH user.
/roles; /roles/{id}; /permissionsGET roles/permissions; POST roles; PATCH/DELETE role.

This is a route index, not an OpenAPI specification. Field-level checks live in the HTTP handlers.

Error handling

StatusTypical cause
