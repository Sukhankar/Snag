Find the failing boundary.

Start with container state, then work from the API out to the browser.

SymptomCheck
Containers fail to startRun docker compose ps and docker compose logs server postgres. Check required environment variables.
Health check returns 503The API cannot reach PostgreSQL. Check database health and DATABASE_URL.
Widget returns 403Match scheme, host, and port against allowed origins. Check the project key and active state.
Widget returns 400Send a valid reporter token: 16–64 URL-safe characters.
Owner login fails after editing .envBootstrap runs only once. Reset the existing account using the recovery command.
Dashboard returns 502Check server-side SNAG_API_URL and API reachability from the dashboard container.
SSE does not updateCheck proxy buffering and connection timeouts; use one API replica.
Browser tests cannot launchInstall Chrome or set CHROME_PATH. playwright-core does not bundle a browser.
Local/LAN login does not stickFor plain HTTP on a non-localhost LAN host, review COOKIE_SECURE. Use HTTPS for deployment.
Too many requests / 429Wait for the limiter; verify test rate settings and proxy IP handling.
