DEVELOPER FIELD GUIDE / 05

Configuration, without guesswork.

Environment variables are read by the Go API, the dashboard, or Docker Compose. Their scope matters.

API environment

VariableDefault / purpose
DATABASE_URLRequired PostgreSQL connection string. Compose constructs it.
SNAG_ADDR:8080
SNAG_OWNER_EMAIL / SNAG_OWNER_PASSWORDOwner bootstrap on first start.
SNAG_OWNER_NAMEOwner display name; Compose defaults to Owner.
SNAG_ADMIN_TOKENOptional full-access service token, at least 24 characters. Empty disables it.
SNAG_WIDGET_FILEPath to widget.min.js; container sets /srv/widget.min.js.
SNAG_MAX_TICKET_MB20; accepts integers from 1 to 200.
SNAG_CREATE_PER_MINUTE10 ticket submissions per project + IP.
SNAG_TRUST_PROXYfalse; enable only behind a proxy that overwrites forwarded IP headers.
SNAG_DEMO_PROJECT_KEYOptional demo project bootstrap key.
SNAG_DEMO_ORIGINSComma-separated allowed demo origins.

Compose and dashboard

VariablePurpose
POSTGRES_PASSWORDDatabase password consumed by Compose.
SNAG_API_URLServer-side API origin. Compose uses http://server:8080.
COOKIE_SECUREtrue by default; false only for plain-HTTP local/LAN development.
A value in .env reaches a container only when Compose passes it through. Add missing environment entries to docker-compose.yml when enabling API options such as SNAG_TRUST_PROXY.

What belongs in Git

Keep reviewed .env.example templates in source control. Real environment files, credentials, database volumes, builds, logs, and generated screenshots are ignored.

Limits

Ticket creation has its own project/IP rate limit. Other widget traffic is limited to 240 requests per minute with a burst of 60. Login has IP and account limits. See router.go for exact enforcement.
