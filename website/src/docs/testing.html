DEVELOPER FIELD GUIDE / 07

Make the happy path earn it.

Run these examples against a development instance. The write examples create actual records.

Prepare the examples

Start Compose and the widget demo host. Use a project that allows http://localhost:5173. Set the project key from your dashboard. The reporter token below is a disposable test identity, not an admin credential.

Terminal
export PROJECT_KEY='pk_your_project_key'
export REPORTER_TOKEN="$(openssl rand -hex 16)"

1. Check connectivity

Terminal
curl -i http://localhost:8080/healthz

Expect HTTP 200 and {"status":"ok"}.

2. Create a ticket

Terminal
curl -i http://localhost:8080/api/v1/widget/tickets \
  -H 'Origin: http://localhost:5173' \
  -H "X-Project-Key: $PROJECT_KEY" \
  -H "X-Reporter-Token: $REPORTER_TOKEN" \
  -H 'Content-Type: application/json' \
  --data '{"title":"Receipt is blank","category":"bug"}'

Expect HTTP 201. Copy the returned ticket_code; do not assume a fixed ticket number.

3. Read your report

Terminal
export TICKET_CODE='replace-with-returned-code'
curl -i "http://localhost:8080/api/v1/widget/tickets/$TICKET_CODE" \
  -H 'Origin: http://localhost:5173' \
  -H "X-Project-Key: $PROJECT_KEY" \
  -H "X-Reporter-Token: $REPORTER_TOKEN"

Expect HTTP 200 and the public ticket conversation. Reuse the same reporter token.

4. Check rejection paths

ChangeExpected result
Send Origin: https://not-allowed.example403 for a disallowed origin.
Remove X-Reporter-Token400 on widget ticket routes.
Submit an empty title422 validation failure.
GET /api/v1/admin/tickets without a bearer token401.

Repository suites

For the smoke and widget suites, configure an API SNAG_ADMIN_TOKEN and pass the same value as ADMIN_TOKEN. Set OWNER_EMAIL and OWNER_PASSWORD for the RBAC and dashboard tests. Do not use production credentials.

Terminal
server/scripts/smoke.sh
server/scripts/rbac.sh
cd e2e
npm ci
npm run widget
npm run dashboard
npm run users

Browser suites use playwright-core and local Chrome. Set CHROME_PATH if Chrome is not at /usr/bin/google-chrome. API: 8080; dashboard: 3000; demo host: 5173. Tests mutate data and create local screenshots.

Rate-limit test

Set the API’s SNAG_CREATE_PER_MINUTE=5, restart it, and run:

Terminal
EXPECT_CREATE_LIMIT=5 server/scripts/smoke.sh

The examples describe expected behaviour; this documentation does not claim the backend suites were run during the website build.
