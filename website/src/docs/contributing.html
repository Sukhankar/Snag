DEVELOPER FIELD GUIDE / 10

Develop against the same stack.

Keep the API, widget, dashboard, and tests together in the monorepo.

Local prerequisites

The container builds use Node.js 24 and Go 1.26. PostgreSQL 17 runs in Compose. Install Go and Node locally only if running modules outside their containers.

Run modules separately

Terminal
cd widget
npm ci
npm run build
npm run demo
Terminal
cd server
# Set DATABASE_URL and first-start Owner credentials.
export SNAG_WIDGET_FILE=../widget/dist/widget.min.js
go run ./cmd/snag
Terminal
cd dashboard
npm ci
cp .env.example .env.local
npm run dev

Run each block from the repository root in its own terminal. The dashboard environment template points to the local API.

Before a change lands

  • Keep credentials out of tracked files and use environment templates.
  • Update API consumers when request or response shapes change.
  • Run relevant browser and API suites against development data.
  • Document configuration changes and database migration implications.

Working on this website

The website/ directory contains a dependency-free static site. Pages live in src/; the build copies them into dist/.

Terminal
cd website
npm run build
npm test
npm run dev
# Open http://localhost:4173
