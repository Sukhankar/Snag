DEVELOPER FIELD GUIDE / 01

Your first report.

Run Snag locally, sign in, and send a ticket from the demo application.

1. Prepare the stack

You need access to the private repository, Git, and Docker with Compose. Node.js is only needed for the local demo host.

Terminal
git clone https://github.com/Sukhankar/Snag.git
cd Snag
cp .env.example .env
# Set your database password and Owner credentials.
docker compose up --build -d

Before starting Compose, edit .env and replace the example database and Owner passwords. Set SNAG_OWNER_EMAIL to the account you will use.

2. Sign in

Open localhost:3000. The Owner is bootstrapped on first start. Sign in using your configured email and password.

Changing Owner variables after the first start does not reset an existing account. Use My account, or the recovery command in the deployment guide.

3. Try the widget

Terminal
cd widget
npm ci
npm run demo

Open localhost:5173 and press Alt+B. The example environment configures a demo project with this origin. Submit a report and check the dashboard inbox.

4. Connect your own application

In Projects, create a project and add its allowed origin, including its scheme and port. Copy the generated script tag into your application. See widget integration.

Check the result

Terminal
curl -i http://localhost:8080/healthz

A healthy database produces HTTP 200 and {"status":"ok"}. Keep the pgdata volume when stopping containers.
